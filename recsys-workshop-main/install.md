# Installation Guide

## Prerequisites

You will need:
* pandas
* scikit-learn
* matplotlib
* urllib3
* Flask
* Git
* Git LFS


## Installation Steps

1. Step one (install git lfs - needed to get apperances.csv).
2. Step two (clone repo).
3. Step 3 (make sure you are on branch "main")

## Post‑install / Verification

* How to test that it worked:
 cd to src
 run python3 server.py
 go to http://127.0.0.1:5000
